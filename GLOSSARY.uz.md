# Oʻzbekcha atamalar lugʻati (Uzbek terminology glossary)

The Uzbek edition (`src/uz/`, `.vitepress/config/langs/uz.ts`) uses these terms. Follow them for any new or edited Uzbek content, including code comments.

## Core terms
| English | Uzbek |
| --- | --- |
| Design Patterns | Loyihalash andozalari (first mention on a page: "Loyihalash andozalari (Design Patterns)") |
| design pattern | loyihalash andozasi |
| pattern | andoza (andozasi, andozalar, andozani, andozaning, andozadan, andozalardan, ...) |
| anti-pattern | anti-andoza |
| Creational Patterns | Yaratuvchi andozalar |
| Structural Patterns | Tuzilmaviy andozalar |
| Behavioral Patterns | Xulq-atvor andozalari |
| Architectural Patterns | Arxitektura andozalari |

Do not use "pattern", "namuna" or "dizayn namunalari/patternlari" for *pattern*; use the andoza forms with the correct suffixes. "namuna" in the sense of "example/sample" (e.g. "kod namunasi") is fine.
