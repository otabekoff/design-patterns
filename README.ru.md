# Паттерны проектирования

Languages: [English](README.md) | [Oʻzbek](README.uz.md) | [Русский](README.ru.md) | [Türkçe](README.tr.md) | [العربية](README.ar.md) | [Deutsch](README.de.md) | [Español](README.es.md)

Полный справочник с поиском по паттернам проектирования программного обеспечения — порождающим, структурным, поведенческим и архитектурным — с диаграммами и параллельными примерами на TypeScript, Python, Java, Go и Rust.

**Сайт:** https://otabekoff.github.io/design-patterns/

## Возможности

- 41 паттерн, у каждого — аналогия, структурная диаграмма Mermaid, реализации на пяти языках, типичные ошибки и вопросы для собеседований
- Руководство «Выбор паттерна» и страницы сравнения паттернов (Strategy vs State, Decorator vs Proxy, …)
- Версии на английском и узбекском языках
- Локальный полнотекстовый поиск, светлая и тёмная темы, а также запоминание выбранного языка кода между страницами
- Действия «Copy Markdown» и «Open in ChatGPT / Claude» на каждой странице

## Стек технологий

[VitePress](https://vitepress.dev) (Vue 3 + Vite), Mermaid, иконки Lucide, развёртывание на GitHub Pages. В качестве менеджера пакетов и средства запуска скриптов используется [Bun](https://bun.sh).

## Быстрый старт

```bash
bun install
bun run dev        # http://localhost:5173/design-patterns/
```

## Скрипты

| Команда | Что делает |
| --- | --- |
| `bun run dev` | Запускает dev-сервер |
| `bun run build` | Собирает статический сайт в `.vitepress/dist` (завершается с ошибкой при битых ссылках) |
| `bun run preview` | Локально раздаёт production-сборку |
| `bun run check` | Запускает все проверки контента, перечисленные ниже |
| `bun run check:mermaid` | Разбирает каждую диаграмму Mermaid |
| `bun run check:code` | Проверяет синтаксис каждого примера кода (TS/JS через esbuild, Python, Java, Go, Rust — отсутствующие тулчейны пропускаются) |
| `bun run check:i18n` | Сравнивает каждую английскую страницу с её узбекским переводом (отсутствующие страницы, расхождения в коде и диаграммах) |
| `bun run images` | Перекодирует обложки и изображения карточек в WebP и заново генерирует изображения для соцсетей (нужны Python и Pillow) |

## Структура проекта

```
src/                     # Контент (английский — в корне)
  creational/ structural/ behavioral/ architectural/
  comparisons/           # Страницы сравнения паттернов
  uz/                    # Узбекский перевод с той же структурой путей
public/                  # Статические ресурсы: covers/, cards/, og/ (изображения для соцсетей), иконки
.vitepress/
  config/                # Конфигурация сайта, nav/sidebar для каждой локали (langs/), плагины markdown
  theme/                 # Переопределения темы и Vue-компоненты (CoverImage, Card, Mermaid, …)
scripts/                 # Проверки контента и конвейер обработки изображений
```

## Написание контента

- Каждая страница начинается с frontmatter: `title`, `description` и `icon` (имя иконки [Lucide](https://lucide.dev/icons) в PascalCase, отображается в боковой панели).
- Группируйте реализации с помощью `::: code-group` и подписывайте вкладки названием языка, например ` ```python [Python] `.
- Диаграммы размещаются в блоках ` ```mermaid `.
- Добавляйте новые страницы в боковую панель в `.vitepress/config/langs/en.ts` и `uz.ts`.
- Переводы лежат по тем же путям в `src/uz/`; блоки кода должны совпадать с английской версией (комментарии можно переводить), затем запустите `bun run check:i18n`.
